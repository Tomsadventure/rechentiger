# Rechentiger

Plus und Minus bis 100 für die 2. Klasse – mit Tiko, dem Tigerbaby. 10 Stufen (Lehrplan 21), Tipps mit Rechenweg und
Zehnerstangen, Sticker-Album. Fürs iPad, iPhone und den PC; läuft auch ohne Internet (Safari → Teilen → «Zum Home-Bildschirm»).

Dieser Ordner wird von `Scripts/bauen.py` im Projekt `Rechentiger` erzeugt – hier nichts von Hand ändern, es wird überschrieben.
